# vaynsiy-content

Материалы редакции VAYN SIY для сайта https://vaynsiy.com.

`articles.json` — список статей (новые сверху). Сайт читает этот файл напрямую, поэтому новая статья появляется на сайте через 1–2 минуты после коммита, без публикации сайта на Netlify.

Формат записи и правила редакции — в репозитории сайта, `tools/REDAKCIYA.md`.
